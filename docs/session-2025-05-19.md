## 완료된 작업

### 1. i18n 전면 적용 (EN/KO 다국어)

**아키텍처**
- `lib/i18n.ts` — 모든 번역 키/값 저장소. `t(key, locale)` 함수로 조회, EN 폴백 지원
- `app/providers.tsx` — `useLocale()` 훅으로 앱 전체 locale 상태 공유 (`'en' | 'ko'`)
- 사이드바에 EN/KO 토글 버튼 추가

**번역 완료 파일 목록**

| 파일 | 키 그룹 |
|------|---------|
| `app/assets/page.tsx` | `assets.*` |
| `app/licenses/page.tsx` | `licenses.*` |
| `app/hr/page.tsx` | `hr.*` |
| `app/hr/[company]/page.tsx` | `hr.*`, `common.*` |
| `app/hr/components/HrSummaryCards.tsx` | `hr.cards.*` |
| `app/hr/components/AttendanceGrid.tsx` | `grid.*` |
| `app/hr/components/EmployeeSearch.tsx` | `emp.*` |

**주요 번역 키 그룹**
- `common.*` — 공통 (save, cancel, delete, add, loading 등)
- `nav.*`, `sidebar.*` — 네비게이션
- `auth.*` — 로그인 화면
- `assets.*` — IT 자산 관리
- `licenses.*` — 구독/M365 관리
- `hr.*`, `hr.cards.*` — HR 대시보드
- `grid.*` — 근태 그리드 (DOW, CODE_OPTIONS, 모달 전체)
- `emp.*` — 직원 검색 패널 (연차/병가/월별/비용 섹션, 모달 전체)
- `month.1` ~ `month.12` — 월 이름

**AttendanceGrid 특이사항**
- 기존 `const t = todayIso()` 로컬 변수가 번역 함수 `t`와 충돌 → `const todStr = todayIso()`로 rename
- `CODE_OPTIONS` 정적 배열에서 `label` 필드 제거, 렌더링 시 `t('grid.code.X', locale)` 조회
- `DOW` 배열 제거, 인라인 `t('grid.dow.N', locale)` 사용

**EmployeeSearch 특이사항**
- 동일하게 `const t = todayIso()` → `const todStr` rename
- `fmtDateLong(iso, locale)` — locale 파라미터 추가, EN: `May 19, 2025` / KO: `2025년 5월 19일`
- `MO` 배열 제거, `t('month.N', locale)` 사용
- 숫자+단위 헬퍼: `const days = (n) => locale === 'ko' ? '${n}일' : '${n} days'`

### 2. TypeScript 빌드 에러 수정

**원인**: Supabase PostgREST join은 항상 배열을 반환하는데, 타입 정의가 단일 객체로 되어 있었음

**수정 파일 및 내용**

`app/assets/page.tsx`
```typescript
// 전
employees: { name: string } | null
// 후
employees: { name: string }[] | null
```
- `a.employees?.name` → `a.employees?.[0]?.name` (3곳)

`app/licenses/page.tsx`
```typescript
// 전 (License, Subscription, SubEmployee, SubEmpRow 타입)
employees: { name: string } | null
// 후
employees: { name: string }[] | null
```
- `.employees?.name` → `.employees?.[0]?.name` (5곳)

### 4. 환경변수 주의사항

CLI 배포 시 `.env.local`에서 Supabase 키가 제거되는 현상 발생:
```
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- NEXT_PUBLIC_SUPABASE_URL
```

Vercel 대시보드 → **Settings → Environment Variables**에 반드시 세팅 필요:
| Key | 설명 |
|-----|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon key |
