### 1. Licenses 페이지 — 이메일 플랜 매니저 + Sort + 오너 수정

**이메일 플랜 매니저 (`PlanManagerModal`)**
- `email_plans` 테이블 연동: `{ id, name, monthly_cost_cad }`
- "⚙ Plans" 버튼 → 플랜 목록 인라인 편집 (이름 / 비용 수정·저장)
- "+ Add Plan" 행으로 신규 플랜 추가
- 계정 등록 모달의 Plan 필드: `<select>` 드롭다운으로 변경, 선택 시 Monthly Cost 자동 입력

**Account ID 자동 생성**
- `computeNextAccountId(licenses)` — 기존 ID 중 trailing 숫자 최댓값 + 1
- 패턴: `A-001`, `A-002` …

**Sort 기능**
- 정렬 가능 컬럼: Account ID, Display Name, Type, Plan, Monthly Cost, Status
- 헤더 클릭 → asc/desc 토글, 활성 컬럼 파란색 화살표 표시

**Owner "Unlinked" 수정**
- Supabase join (`employees(name)`)이 RLS/FK 문제로 null 반환
- 해결: join 제거, 별도 `employees` 배열 로드 후 `employees.find(e => e.id === r.employee_id)?.name`으로 클라이언트 조회
- Assets 페이지에도 동일 패턴 적용

**필요한 Supabase SQL** (직접 SQL Editor에서 실행 필요)
```sql
create table if not exists email_plans (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  monthly_cost_cad numeric not null default 0
);
create policy "allow_all_email_plans" on email_plans
  for all using (true) with check (true);
```

### 2. AttendanceGrid — WFH 서브코드 + 셀 메모 + UI 개선

**W1 / W2 / W3 WFH 서브코드**
- `LeaveCode` 타입 확장: `'W1' | 'W2' | 'W3'`
- 색상: W1/W2 `bg-blue-100 text-blue-700`, W3 `bg-blue-50 text-blue-600`
- 집계: W1/W2 = 0.5일, W3 = 0.5일
- ⚠ `leave_entries` 테이블 CHECK 제약 수정 필요:
```sql
alter table leave_entries
  drop constraint if exists leave_entries_code_check;
alter table leave_entries
  add constraint leave_entries_code_check
  check (code in ('L','L1','L2','L3','S','S1','S2','S3','W','W1','W2','W3','T','T1','T2','T3','B'));
```

**셀 메모 (우클릭 노트)**
- 우클릭 → 컨텍스트 메뉴: 📝 Add Note / ✏️ Edit Note / 🗑 Delete Note
- 메모 있으면 셀에 주황색 점(●) 표시, 행 hover 시 툴팁으로 내용 표시
- `attendance_notes(emp_id, day, note)` 테이블 필요:
```sql
create table if not exists attendance_notes (
  id uuid primary key default gen_random_uuid(),
  emp_id uuid references employees(id) on delete cascade,
  day date not null,
  note text not null,
  unique(emp_id, day)
);
create policy "allow_all_attendance_notes" on attendance_notes
  for all using (true) with check (true);
```

**드롭다운 오버레이 개선**
- 기존: `overflow-x-auto` 스크롤 컨테이너 안에서 `absolute` → 잘림
- 수정: `position: fixed`, `getBoundingClientRect()`로 좌표 계산, `w-52` 고정 너비

**CSS 대비 강화**
- 일요일 헤더: `bg-red-200 text-red-600`, 셀: `bg-red-100`
- 토요일 헤더: `bg-sky-200 text-sky-600`, 셀: `bg-sky-100`
- 오늘 헤더: `bg-amber-200 text-amber-800`, 셀: `bg-amber-100`

## 패턴 정리 (다음 세션 참고용)

| 문제 | 해결 방식 |
|------|-----------|
| Supabase join null 반환 (RLS/FK) | join 제거, 별도 배열 로드 후 `.find()` 클라이언트 조회 |
| overflow 컨테이너 안에서 드롭다운 잘림 | `position: fixed` + `getBoundingClientRect()` 좌표 계산 |
| 컨텍스트 메뉴 바깥 클릭 닫기 | `useRef` + `document.addEventListener('mousedown', ...)` |
| 새 레코드 ID 자동 생성 | trailing 숫자 regex + `Math.max()` + `padStart(3, '0')` |
