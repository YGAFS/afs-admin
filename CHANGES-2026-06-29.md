# Changes — 2026-06-29

## 1. Vacation Accrual Fix (AttendanceGrid)

**Problem:** AttendanceGrid used a **calendar-year** basis (Jan 1 reset) while EmployeeSearch used an **anniversary-year** basis (hire date). This caused different numbers to appear for the same employee — e.g., Aradhya Mishra showed 5 days remaining in the grid but 3.03 in the panel.

**Root cause:** Calendar-year model underestimates carryover for mid-year hires (only 2.68 days vs. the correct 5 days for someone who started Sep 24).

**Fix:** Replaced `calcAccrued()` with `calcAnnivVacStat()` in `app/hr/components/AttendanceGrid.tsx`.
- Computes all anniversary periods from hire date to today
- Cascades carryover (max 5 days) through each period
- Grid now matches Employee Search panel values

---

## 2. Bulk Holiday Column Feature (AttendanceGrid)

**File:** `app/hr/components/AttendanceGrid.tsx`

Click any **day column header** in the attendance grid to open a dropdown menu with:

- **Set Holiday (B) for All** — upserts `B` (Holiday) for all active employees on that day. Automatically skips employees whose start_date is after that day, or whose end_date is before it.
- **Clear All This Day** — deletes all leave entries for every employee on that day.

## 3. Email Report — Month Navigation

**File:** `app/hr/[company]/page.tsx`

The calendar in the Send Report modal now has **‹ Month Year ›** navigation buttons, allowing date selection across multiple months.

- `emailDates` changed from `Set<number>` (day-only) to `Set<string>` (ISO dates like `2026-07-03`) to support cross-month selection
- Navigating months re-fetches leave entries for that month
- `buildEmailBody()` updated to work with ISO date strings

## 5. Email Report — CC Field

**File:** `app/hr/[company]/page.tsx`

Added a **CC** section below the To field in the report modal.

- Shows checkboxes for all contacts in the recipients list **except** the currently selected To
- Supports multi-select
- Selecting a contact as To automatically unchecks them from CC
- CC emails are appended as `cc=` in the mailto link
- Hidden when only one recipient contact exists

## 6. Email Report — From Sender Name as Signature

**File:** `app/hr/[company]/page.tsx`

`from=` is not supported by Outlook's mailto handler (ignored even if the account is logged in). As a workaround, the selected **From** contact's name is appended as a signature at the bottom of the email body:

```
Thank you.

Yun Gyeong
```
